# 디랙토리 실습
```
%mkdir terminal_test 
%ls #디랙토리가 올바르게 생성되었는지 확인
codyssey_test	Dockerfile	index.html	README.md	terminal_test

%cd terminal_test
%echo "테스트용" > test.txt #새로 파일을 만들면서 안에 내용 쓰기

%cat test.txt #파일 내용 출력
테스트용

%mv test.txt hello.txt  #파일의 이름을 hello.txt로 바꾸기
%ls # 올바르게 바뀌었는지 확인하기
hello.txt

%cp hello.txt  test1.txt #test1.txt라는 파일에 내용을 카피하기
%cat test1.txt #카피가 잘 되었는지 내용 출력을 통해 확인하기
테스트용

%rm test1.txt #파일 삭제하기
%ls # 삭제가 잘 되었는지 확인하기
hello.txt
```
# 기능 정리
| 분류 | 명령어 | 설명 및 주석 |
| --- | --- | --- |
| **디렉토리 생성 및 이동** | `mkdir 폴더명` | 새로운 디렉토리(폴더) 생성하기 |
|  | `cd ..` | `#처음(상위)으로 이동하기` |
|  | `cd 폴더명` | 하위 디렉토리로 이동하기 |
|  | `cd ~` | 홈 디렉토리로 이동하기 |
| **파일 및 디렉토리 관리** | `mv 파일명 이동할위치/` | 파일이나 디렉토리를 다른 경로로 이동하기 (파일 이름 변경에도 사용) |
|  | `cp 원본파일 복사할파일` | 파일 복사하기 |
| **삭제** | `%rm -rf terminal_test` | `#폴더 안에 있는 것을 포함하여 모두 삭제 하기` |
|  | `%rm` | 파일과 디렉토리 모두 삭제 가능 |
|  | `%rmdir` | 오직 디렉토리만 삭제 가능 (파일 삭제 불가) |
