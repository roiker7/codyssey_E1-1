GitHub Push 거부 오류 (GitHub 원격 저장소와 로컬 저장소의 동기화 충돌)

문제 상황:
로컬에서 작업한 내용을 git push 하려고 했으나, 
[rejected] main -> main (fetch first) 오류가 발생하며 업로드가 거부됨.

원인 가설:
GitHub 웹사이트에서 직접 README.md를 수정하거나 파일을 생성한 적이 있음.
이로 인해 GitHub에는 있지만 로컬PC에는 없는 커밋이 존재하여,
두 저장소의 히스토리가 일치하지 않아 충돌이 발생했을 것임.

확인:
GitHub 저장소 페이지에 접속하여 확인해본 결과 
GitHub와 vscode에 저장된 폴더와 파일들이 다르다는 것을 확인함

해결: git pull origin main 명령어를 통해 원격의 변경 사항을 먼저 로컬로 가져온 뒤,
다시 git push를 시도햐였지만 여전히 되지 않아서 깃허브에서 중요한 내용을 따로 저장한 뒤에
git push -f로 강제로 덮어써 해결함

대안: 협업 시에는 작업 시작 전 항상 git pull을 습관화하여 싱크를 맞추어야 하며, 
만약 강제로 덮어써야 하는 상황이라면 git push -f를 쓸 수 있으나 주의가 필요함을 학습함.
