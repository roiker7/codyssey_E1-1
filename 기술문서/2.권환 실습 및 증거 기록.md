# 목록들 권환 확인하기
```
%ls -l 
-rw-r--r--  1 roiker78137  roiker78137    0  7 30 16:21 test1
drwxr-xr-x  2 roiker78137  roiker78137   64  7 30 16:21 test2
```
```
- rwx rwx rwx
│  │   │   └ 기타(others)
│  │   └ 그룹(group)
│  └ 소유자(user)
└ 종류 (-=파일, d=디렉토리)
```
| 숫자 | 권한 문자 | 의미 | 영문 |
| --- | --- | --- | --- |
| 4 | r | 읽기 | Read |
| 2 | w | 쓰기 | Write |
| 1 | x | 실행 / 디렉토리 진입 | Execute |

| 권한 조합 | 숫자 값 | 설명 |
| --- | --- | --- |
| rwx | 7 (4+2+1) | 파일을 읽고, 수정하고, 실행하는 등의 모든 작업이 가능 |
| rw- | 6 (4+2+0) | 파일을 열어서 보거나 수정할 수는 있지만, 프로그램처럼 실행할 수는 없음 |
| r-x | 5 (4+0+1) | 파일 내용을 보거나 프로그램·스크립트를 실행할 수는 있지만, 내용을 수정하거나 삭제할 수는 없음 |
- macOS 기본 권한은 파일 644 / 디렉토리 755 이다.
- chmod는 숫자로 소유자·그룹·기타 권한을 한 번에 지정한다.
- 디렉토리의 x는 "진입(cd) 권한" 을 의미한다.
- 777은 모두에게 모든 권한을 주므로 보안상 위험 
- ls -l(파일) / ls -ld(디렉토리 자체) 로 권한을 확인한다.



```
#파일 권환을 나, 그룹, 기타 모두가 읽고 쓰고 접근할 수 있게 바꾼다
%chmod 777 test1 

#디렉토리의 권환을 나, 그룹, 기타 중 나만 읽고 쓰고 접근할 수 있게 바꾼다
%chmod 700 test2 


#권환이 잘 바뀌었는지 확인하기
%ls -l 
-rwxrwxrwx  1 roiker78137  roiker78137    0  7 30 16:21 test1
drwx------  2 roiker78137  roiker78137   64  7 30 16:21 test2
```
